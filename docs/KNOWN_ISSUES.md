# 已知限制

开源版本已修复全新数据库的 username/password_hash 字段初始化与兼容迁移、词表字典读取、前端三次作答与测试同步。前两次答错显示提示，第三次答错才加入错题本；请求失败不消耗本地作答次数，提交期间阻止重复点击。

## 功能边界

- 生产题库、书籍、图片、音频和视频目录不包含在仓库中，依赖这些资源的接口会为空或返回资源不存在。
- 当前小程序没有完整语音对话入口。后端中已有朗读、阅读和推荐接口，并不代表小程序已接入全部界面。
- 作答次数由客户端提交，服务端没有跨设备维护题目尝试状态；这不是防作弊或严格学习评测系统。
- 前端自动测试模拟页面和 API，尚未完成微信真机验收。

## 部署风险

- TOKEN_SECRET 有弱默认值，程序没有强制校验。部署者必须设置自己的强随机值，并在正式环境关闭 DEV_MODE、配置家庭白名单。
- 用户密码目前采用加盐 SHA-256，尚未迁移到专用密码慢哈希；登录/注册也缺少完整滥用防护。不应直接作为面向陌生用户的公网服务。
- 程序保存身份标识、昵称、年级、作答、错题和打卡，部署者需要明确访问、保留和删除方式。
- 部分学习音频与插图接口允许无认证访问，只应放置有权公开分发的素材。不要把私人录音或用户上传文件放入这些资源路径。
- 模型和朗读服务可能接收学习文本或题目图片，实际使用前应明确告知数据流向。
- 依赖与镜像没有完全锁定。MP3 转码分支依赖 ffmpeg，而现有 Dockerfile 未安装它。
- 真实模型、微信登录、OCR 推理、在线 TTS、Docker 构建和 HTTPS 尚未做端到端验证。

本项目适用于自行审阅和部署的家庭实验环境；这些限制不代表已经完成全面安全审计。
